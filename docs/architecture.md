# Architecture — PipelineMint

## Milestone 1 (current)
- Next.js App Router web app.
- Server route handler for `/api/leads`.
- Deterministic demo dataset for recruiter/client demos.
- Responsive B2B SaaS UI with pipeline dashboard.

## Milestone 2
- PostgreSQL via Supabase.
- Organizations, users, memberships, leads, activities, tasks, webhooks.
- Row-level security by organization.
- Email/password + OAuth authentication.
- RBAC: admin / manager / member.

## Milestone 3
- AI summarization and next-action suggestions through a server-only provider adapter.
- Queue-backed enrichment jobs.
- Public lead capture form and signed webhook ingestion.
- Telegram connector adapter.

## Milestone 4
- Audit log, rate limiting, idempotency keys, integration secrets vaulting.
- E2E tests and deployment pipeline.
- English/Russian localization.
